# 需求方补充答复

1. 任意历史问题都可以修改或删除，包括第一条问题。
2. 修改第 N 个问题时：
   - 第 1 至 N-1 轮原问题、回答和图表保留。
   - 第 N 个问题文本替换为新问题，原回答和图表失效。
   - 第 N 个问题之后的原问题文本继续展示，但其旧回答和图表全部失效，不再进入 Agent 当前上下文。
   - 系统不自动重跑后续问题；用户可以手动重新执行已失效的问题。
3. 删除第 N 个问题时：
   - 删除第 N 个问题、回答和图表。
   - 同时删除其后的全部问题和问答内容，直到当前对话末尾。
   - 第一条问答之前上传的数据集继续保留。
4. 删除第一条问题后，对话历史变为空，用户可以从数据集重新提问。
5. 修改或删除后，Agent 当前上下文只能使用界面中仍然有效并展示的问答。
6. 本轮不做删除撤销、批量编辑、多人协作和重新编辑 Agent 回答。
7. 修改后重新回答失败时，新问题文本保留，旧回答和图表仍失效；界面提供重试。
