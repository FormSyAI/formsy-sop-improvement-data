## 对照原则

- 同题、同模型、同参数。
- Baseline 不加载 SOP。
- SOP 组加载固定版本 SOP。
- 两组初始设计和共同澄清后的最终设计分别保存。
- API 密钥不写入任何记录。

## 边界

- 只比较产品 SOP 和需求设计。
- 不比较代码实现。
- 不比较实际运行结果。
- 单案例结果不是统计显著性证明。
- SOP 组知道正在使用 FormSy 规范，因此不能解释为纯盲测。
- 当前输出仍可能覆盖不全，尤其是在安全、法规、现有系统能力和具体业务参数上。
