# 实验室设备维修管理 产品SOP（草案 v0.1）

**模式**：generate（首次生成）｜**状态**：草案，未经用户确认｜**依据**：仅用户本次描述，无其他来源。以下标注【事实】=用户原话，【建议】=本方案设计，【待确认】=需用户决定。

---

## 1. 用户、问题与目标

- 【事实】使用者：实验室设备使用人、维修人员。
- 【事实】问题：设备故障后报修、维修、验收缺乏统一流程；维修期间设备仍可能被预约。
- 【建议】目标：故障从报告到验收闭环可追踪，维修期间设备自动不可预约，全程留痕可查。

## 2. 范围

**范围内（首版建议）**
- 故障报告（使用人提交）
- 接单与诊断（维修人员）
- 维修 / 转外修
- 使用人验收
- 维修期间预约锁定

**范围外（首版建议，待确认）**
- 预防性维护计划、设备台账/采购管理、备件库存管理、维修费用结算、多实验室跨机构派单、移动端。

## 3. 角色与权限

| 角色 | 权限 |
| --- | --- |
| 使用人 | 提交/撤回自己的报修单；查看自己相关单据进度；执行验收（通过/驳回）；无接单与维修操作权限 |
| 维修人员 | 查看待接单列表；接单、诊断、登记维修结果或转外修；结束维修提交验收；不能创建报修单的验收结论 |
| 管理员【建议】 | 查看全部单据、重新派单、处理超时/争议、维护设备清单与维修人员名单 |
| 系统 | 维修流程触发后自动锁定该设备预约，验收通过后自动解锁【建议】 |

【待确认】是否需要管理员角色；维修人员是否分内部/外修供应商两类账号。

## 4. 完整流程（用户旅程）

**正常路径**
1. 使用人发现故障 → 填写报修单：设备、故障描述、发生时间、影响程度（如：影响实验进度/影响安全/仅不便）【建议分级】→ 提交。
2. 系统校验设备存在且无进行中维修单 → 生成报修单（状态：已提交）→ **自动锁定该设备预约**。
3. 维修人员查看待接单 → 接单（诊断中）→ 登记诊断结论。
4. 分支 A：可内部维修 → 维修（维修中）→ 填写维修记录（原因、措施、更换件）→ 提交验收（待验收）。
5. 分支 B：需外修 → 填写转外修原因与预计周期（外修中）→ 外修返回后登记结果 → 提交验收（待验收）。
6. 使用人验收：通过 → 单据关闭（已关闭），设备预约解锁；驳回 → 退回维修人员（维修中），附驳回原因，重新处理。

**状态机**

```
已提交 → 诊断中 → 维修中/外修中 → 待验收 → 已关闭
                ↘ 已取消（使用人撤回或管理员终止）
待验收 --驳回--> 维修中
```

## 5. 异常与边界

| 场景 | 产品行为【建议】 |
| --- | --- |
| 重复报修同一设备 | 系统提示已有进行中维修单，禁止重复创建；使用人可补充说明 |
| 报修后设备实际可用（误报） | 使用人可撤回（仅“已提交/诊断中”阶段）；已进入维修后需维修人员终止并注明 |
| 无人接单超时 | 超过阈值（如24h，待确认）提醒管理员；不自动改派 |
| 外修超期 | 标记超期并提醒；不自动关闭 |
| 验收长期不响应 | 超时提醒使用人与管理员；【待确认】超时是否自动视为通过 |
| 维修期间有人尝试预约 | 预约入口显示“维修中，不可预约”及预计恢复时间（如有） |
| 驳回后反复争议 | 管理员仲裁入口【建议】 |
| 撤回/终止维修单 | 预约锁同步解除，记录操作人与原因 |

## 6. 数据与留痕

**报修单字段**：单号、设备ID、报修人、故障描述、影响程度、发生时间、状态、时间戳（提交/接单/完成/验收）、诊断结论、维修记录或外修信息、验收结论、驳回原因、操作日志。

**留痕规则【建议】**：每次状态变更记录操作人+时间+原因；驳回、撤回、终止、仲裁必须填原因；记录不可删除，仅可追加。设备与维修单关联，历史维修可按设备查询。

## 7. 验收设计

| 验收ID | 条件 | 断言 |
| --- | --- | --- |
| AC1 | 使用人提交有效报修单 | 单据生成、状态“已提交”、设备预约被锁定 |
| AC2 | 维修人员接单并内部维修完成提交 | 状态到“待验收”，维修记录完整 |
| AC3 | 转外修流程 | 外修原因与记录留痕，返回后进入“待验收” |
| AC4 | 验收通过 | 状态“已关闭”，预约解锁，可重新预约 |
| AC5 | 验收驳回 | 状态回“维修中”，驳回原因留痕 |
| AC6 | 重复报修 | 被拦截并提示 |
| AC7 | 维修期间预约 | 被拒绝并显示原因 |

【待确认】验收环境（是否已有预约系统可对接——这是技术待承接项 H1）。

## 8. 待确认事项（按影响排序）

1. **预约锁定机制**：是否已有设备预约系统？锁定如何实现？（技术待承接，影响 AC1/AC4/AC7）
2. **影响程度分级**：采用什么分级（如三级）？是否影响派单优先级？
3. **是否需要管理员角色**及仲裁/改派权限？
4. **接单超时阈值**与验收超时是否自动通过？
5. **通知方式**：状态变化是否需要消息提醒（站内/邮件）？
6. **外修供应商**是否需要独立账号填报进度？
7. 范围外项（预防性维护、费用、备件）确认排除。
