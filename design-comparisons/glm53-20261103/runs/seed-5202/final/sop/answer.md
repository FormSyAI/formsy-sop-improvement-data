# 产品 SOP：对话历史问题的修改与删除（v0.2）

> 本版本在 v0.1 草案基础上合并需求方补充答复。答复中明确的行为标记为**已确认**；未答复项保留为**待决定**。本文档为产品行为设计，不进入代码实现。

---

## 0. 范围与对象

- **产品**：自然语言数据查询工具（上传销售数据 → 连续提问 → Agent 分析 → 可生成图表）。
- **本次范围**：对已提交历史问题的修改与删除，及其对回答、图表、对话历史和 Agent 上下文的影响。
- **范围外（已确认）**：删除撤销、批量编辑/删除、多人协作、重新编辑 Agent 回答——本轮均不做。

**已确认的核心行为**（来自开发请求原文 + 需求方答复）：
1. 任意历史问题（含第一条）均可修改或删除。
2. 修改第 N 问：前 1~N-1 轮完整保留；第 N 问文本替换、原回答与图表失效；第 N 问之后的**问题文本继续展示**，但其旧回答和图表全部失效，不进入上下文；系统不自动重跑，用户可手动重新执行已失效问题。
3. 删除第 N 问：删除第 N 问及其回答、图表，并级联删除其后全部问答直到对话末尾；数据集保留。
4. 删除第一条后历史为空，可从数据集重新提问。
5. Agent 上下文 = 界面中仍然有效并展示的问答。
6. 修改后重答失败：新问题文本保留，旧回答与图表仍失效，界面提供重试。

## 1. 用户与任务

| 项 | 内容 |
| --- | --- |
| 使用者 | 已上传数据、正在与 Agent 对话的查询用户 |
| 核心任务 | 修正问错的问题；清理不需要的问题及回答 |
| 目标结果 | 修改后得到基于正确问题、与有效上下文一致的新回答；删除后历史干净，后续回答不受已删内容影响 |

## 2. 操作位置与行为

### 2.1 入口（建议方案，交互形态待确认）

| 入口 | 位置 | 动作 |
| --- | --- | --- |
| E1 | 每条历史问题气泡上的操作（编辑、删除） | 修改 / 删除该问题 |
| E2 | 问题气泡进入编辑态 | 修改文本后重新提交 |
| E3 | 删除确认弹层 | 确认或取消 |

**已确认**：编辑/删除入口仅作用于“问题”；回答不可被用户编辑。任意历史问题（含第一条）均可操作。

**待决定**：
- Q2：编辑后是否显示“已编辑”标记或保留原文可查看？
- Q3：删除确认弹层文案与形式（建议保留确认，文案说明“将同时删除其后 N 轮问答”）。
- 文本长度上限。

### 2.2 修改问题（F-EDIT）【已确认行为】

| 字段 | 规定 |
| --- | --- |
| 触发 | 点击某历史问题的“编辑”，修改文本后提交 |
| 前置 | 该问题已提交（回答生成中的行为见 §6 X3，待决定） |
| 输入 | 新问题文本，非空 |
| 正常行为 | ① 第 1~N-1 轮原问题、回答、图表**保留不变**；② 第 N 问文本替换为新文本，原回答与图表**失效**（不再展示、不进上下文）；③ 第 N 问之后的原问题文本**继续展示**，其旧回答与图表全部**失效**；④ 系统以新问题 + 前面有效轮次为上下文重新回答第 N 问；⑤ **不自动重跑**后续问题 |
| 后续问题 | 已失效的后续问题提供“重新执行”入口（建议：失效问题旁显示可点击的重新执行操作），用户手动触发后按当时有效上下文重新回答 |
| 可见输出 | 第 N 问位置显示新文本与新生成的回答；后续问题文本保留展示，标注失效状态（展示形式待确认） |
| 副作用 | 消耗一次 Agent 调用（费用/额度口径待决定） |

**失效问题的“重新执行”语义（建议，需确认细节）**：重新执行第 M 个失效问题时，上下文 = 第 1~M-1 轮中当前有效的问答 + 第 M 问文本；其后的失效问题保持失效。逐个手动重跑，不级联。

### 2.3 删除问题（F-DELETE）【已确认行为】

| 字段 | 规定 |
| --- | --- |
| 触发 | 点击删除并确认（确认形式待确认 Q3） |
| 正常行为 | 删除第 N 问、其回答与图表，并**级联删除其后全部问题和问答内容直到对话末尾**；数据集保留 |
| 特例 | 删除第一条问题后，对话历史为空，用户可从数据集重新提问（上下文为空 + 数据集） |
| 可见输出 | 界面收缩，剩余历史保持原顺序 |
| 副作用 | 被删内容不再展示、不进上下文；不消耗 Agent 调用；**不可恢复**（本轮已确认不做撤销） |

## 3. 对话历史与 Agent 上下文一致性【已确认规则】

1. **单一事实源**：对话历史（问题 + 有效回答 + 图表引用）是唯一权威记录。
2. **上下文定义（已确认）**：Agent 当前上下文 = 界面中仍然有效并展示的问答。失效、已删除的内容一律不进入。
3. **修改后**：上下文 = 第 1~N-1 轮有效问答 + 第 N 问新文本（重答时）。
4. **删除后**：上下文 = 被删问题之前的有效问答。
5. **图表**：图表是回答的派生物，随所属回答失效/删除而失效/删除；不存在脱离回答的独立图表历史。
6. **一致性断言（验收用）**：任意修改/删除操作后，Agent 的回答不得引用已失效/已删除轮次的内容。

**待决定**：
- Q5：上下文是否有长度/轮次上限及截断策略（若现有产品已有规则，沿用并登记）。
- Q7：对话历史当前是否已持久化（影响中断恢复，属技术待承接查证项）。

## 4. 状态设计

### 4.1 单轮问答状态

| 状态 | 含义 | 出口 |
| --- | --- | --- |
| 已提交（回答生成中） | 问题已保存 | → 已回答 / 回答失败 |
| 已回答 | 问题+回答+可选图表完整展示且有效 | 可被编辑/删除；可因前序操作失效 |
| 回答失败 | Agent 调用失败，问题文本保留 | 可重试 / 编辑 / 删除 |
| 已失效（问题文本保留展示，回答与图表失效） | 因前序轮次被修改而触发；不进上下文 | 用户手动“重新执行”→ 重新生成中；或被级联删除 |
| 已删除 | 从历史移除 | 终态（本轮无撤销） |

### 4.2 状态迁移表

| 当前状态 | 事件 | 下一状态 | 数据/副作用 | 可见结果 |
| --- | --- | --- | --- | --- |
| 已回答（第 N 轮） | 用户编辑并提交 | 重新生成中 | 第 N 问文本替换；第 N 轮旧回答+图表失效；第 N+1 及以后各轮旧回答+图表失效（问题文本保留） | 第 N 位置加载态；后续轮显示失效标注 |
| 重新生成中 | Agent 成功 | 已回答 | 新回答+可选图表入历史 | 展示新回答 |
| 重新生成中 | Agent 失败 | 回答失败 | 新问题文本保留，旧回答仍失效 | 失败提示 + 重试入口【已确认】 |
| 回答失败 | 用户重试 | 重新生成中 | 消耗一次调用 | 加载态 |
| 已失效（第 M 轮） | 用户手动重新执行 | 重新生成中 | 以 1~M-1 有效轮次 + 第 M 问为上下文 | 加载态 |
| 已回答/已失效/回答失败（第 N 轮） | 用户删除并确认 | 已删除（第 N 及其后全部轮次级联删除） | 历史与上下文同步移除 | 界面收缩 |
| 回答生成中（原始提问） | 用户编辑/删除 | **待决定（X3）** | — | — |

## 5. 角色、权限与数据

| 项 | 规定 |
| --- | --- |
| 角色 | 单用户：会话所有者可操作自己会话中的任意问题【已确认无多人协作】 |
| 数据副作用 | 编辑/删除只改变对话历史与上下文；**不改动已上传的数据集**【已确认：删除后数据集保留】 |
| 费用 | 编辑重答与手动重新执行各消耗一次 Agent 调用；删除不消耗。额度/计费口径**待决定** |
| 数据保留 | 删除不可恢复【已确认】；失效内容是否保留内部副本供审计：待决定（不影响用户可见行为） |

## 6. 异常与边界

| ID | 场景 | 行为 |
| --- | --- | --- |
| X1 | 编辑提交空文本 | 前端拦截，提示非空，不发起调用（建议） |
| X2 | 编辑重答失败 | 新问题文本保留，旧回答仍失效，提供重试【已确认】；重试次数上限待决定 |
| X3 | 原始回答生成中发起编辑/删除 | **待决定**。建议：该轮生成中禁用编辑/删除入口，避免结果不明 |
| X4 | 删除第一条问题 | 历史为空，数据集保留，可重新提问【已确认】 |
| X5 | 连续快速多次编辑/重新执行 | 并发口径待决定（建议：前次生成中禁止再次提交或提示等待） |
| X6 | 删除/修改后立即提问 | 上下文已同步，正常回答；断言不引用失效/已删内容 |
| X7 | 会话/页面中断后恢复 | 依赖历史持久化（Q7，技术待承接）；失效状态需在恢复后保持 |
| X8 | 重新执行失效问题时其前序轮次又发生变化 | 上下文按执行时刻的有效轮次组装（建议，需确认） |

## 7. 验收设计

| ID | 场景 | 前置 | 操作 | 可判定断言 |
| --- | --- | --- | --- | --- |
| AC1 | 修改重答 | 按示例完成 3 轮对话 | 编辑第 2 问为“华南地区增长最快的产品是什么？”并提交 | 第 1 轮完整保留；第 2 问显示新文本与针对华南的新回答；第 2 问原回答与图表不再展示；第 3 问文本仍展示、其旧回答与图表失效且不进上下文；系统未自动重跑第 3 问 |
| AC2 | 手动重新执行 | AC1 完成 | 点击第 3 问（画图）的重新执行 | 以第 1 轮 + 新第 2 轮 + 第 3 问为上下文重新回答；新图表生成 |
| AC3 | 删除级联 | 3 轮对话 | 删除第 2 问并确认 | 第 2、3 轮问答及图表全部消失；第 1 轮保留；数据集保留 |
| AC4 | 删除第一条 | 3 轮对话 | 删除第 1 问并确认 | 历史为空；数据集仍在；新提问正常回答且不引用任何已删内容 |
| AC5 | 上下文一致性 | AC3 完成后 | 提问“刚才增长最快的产品是什么？” | 回答不引用已删的华东分析，或明确说明无此前分析可引用 |
| AC6 | 空编辑拦截 | 任意已回答问题 | 清空文本提交 | 提示非空，无 Agent 调用发生 |
| AC7 | 重答失败 | 模拟 Agent 失败 | 编辑提交 | 失败提示可见；新问题文本保留；旧回答仍失效；提供重试入口 |
| AC8 | 删除确认 | 任意 | 点击删除 | 弹出确认（文案含级联范围）；取消则无任何变化 |

**验收环境/数据**：需一份含地区、产品、销售额、时间维度的测试数据集（由需求方提供或授权构造）。本表为设计，实际执行属后续阶段。

## 9. 已确认 / 建议 / 待决定 汇总

**已确认（需求方答复）**：
- 任意问题（含第一条）可修改/删除。
- 修改：前序保留、该轮替换重答、后续问题文本保留但回答图表失效、不自动重跑、可手动重新执行。
- 删除：级联删到末尾；数据集保留；删第一条后历史为空。
- 上下文 = 界面中仍有效并展示的问答。
- 重答失败：新文本保留、旧回答仍失效、提供重试。
- 本轮不做：删除撤销、批量编辑、多人协作、编辑 Agent 回答。

**建议方案（未经确认）**：
- 失效问题旁提供“重新执行”操作及失效标注；重新执行按执行时刻的有效上下文组装（X8）。
- 删除确认弹层及级联范围文案；空文本前端拦截；生成中禁用编辑/删除（X3）。

**剩余待决定**：
- Q2 已编辑标记；Q3 删除确认形式；X3 生成中操作；X5 并发提交口径；X8 重新执行时前序再变化的语义。
- 上下文长度上限（Q5）、历史持久化现状（Q7）、调用费用口径、文本长度上限、重试次数上限、失效内容内部副本保留策略。

**下一问题（建议先答）**：X3——回答仍在生成中时，该轮的编辑/删除入口是禁用还是允许（删除需中止生成）？这是剩余项中唯一影响核心状态机完整性的决定。
