# 产品 SOP：对话式数据分析工具——历史问题修改与删除（最终版）

版本：v1.0（基于需求方 2026 补充答复更新）。本文档为产品行为设计与制作计划，不涉及代码实现，不表示任何功能已开发、测试或上线。除标注“建议”或“未知”的内容外，行为规则均为需求方已确认决定。

## 0. 决定状态分类

| 类别 | 内容 |
| --- | --- |
| **已确认（需求方原文）** | ① 任意历史问题（含第一条）可修改、可删除；② 修改第 N 问：1–N-1 轮完整保留；第 N 问文本替换、其回答与图表失效；第 N 问之后的问题文本继续展示但旧回答与图表全部失效，不自动重跑，用户可手动重新执行；③ 删除第 N 问：级联删除第 N 问及其后全部问答直至末尾；数据集保留；④ 删除第一条后历史为空，可从数据集重新提问；⑤ Agent 上下文 = 界面中仍然有效并展示的问答；⑥ 本轮不做删除撤销、批量编辑、多人协作、编辑 Agent 回答；⑦ 修改后重新回答失败：新问题文本保留、旧回答与图表仍失效、提供重试。 |
| **建议（本文档提出，待确认）** | 入口交互形态、失效态视觉（灰显/折叠）、失败提示文案、审计记录、验收操作细节。 |
| **未知（仍需补充）** | 见 §8，共 3 项。 |

## 1. 用户与问题

- **使用者**：单人使用的会话（本轮确认无多人协作）。
- **问题**：提问写错后错误问题污染上下文且无法回退。
- **目标**：用户可修正或移除任意历史问题，使界面展示历史与 Agent 实际上下文一致。

## 2. 范围

**范围内（已确认）**：修改任意历史问题并重新回答；删除任意历史问题（级联至末尾）；失效态展示；手动重新执行已失效问题；失败重试。

**范围外（已确认本轮不做）**：删除撤销、批量编辑、多人协作、编辑 Agent 回答、自动重跑后续问题、仅删单条保留后续的模式。

## 3. 用户可以在哪些位置做什么

| 位置 | 动作 | 状态 |
| --- | --- | --- |
| 每条用户问题气泡（建议：悬停/长按/“⋯”菜单） | 修改问题、删除此问题及之后 | 已确认能力，入口形态为建议 |
| 内联编辑框 | 编辑文本、确认、取消；确认前展示影响范围提示 | 建议 |
| 删除确认弹层 | 展示将删除的范围（第 N 问至末尾共 M 轮）、确认、取消 | 已确认级联规则，弹层为建议 |
| 已失效的问题条目 | 查看问题文本；（建议）提供“重新执行”入口 | 重新执行已确认，入口形态为建议 |
| 回答气泡、图表卡片 | 无独立编辑/删除入口 | 建议（避免回答与来源问题脱钩） |

## 4. 修改或删除后的变化规则（已确认）

### 4.1 修改第 N 个问题

| 对象 | 变化 |
| --- | --- |
| 第 1 至 N-1 轮 | 问题、回答、图表**原样保留**，继续生效 |
| 第 N 个问题 | 文本替换为新问题 |
| 第 N 轮旧回答与图表 | **失效**（不进入上下文；展示方式为建议：灰显/折叠） |
| 第 N+1 及之后的轮次 | 问题文本**继续展示**；旧回答与图表**全部失效**，不进入上下文 |
| 后续问题 | **不自动重跑**；用户可手动重新执行已失效的问题 |
| 重新回答 | Agent 基于第 1 至 N-1 轮 + 新的第 N 问生成新回答 |

### 4.2 删除第 N 个问题

| 对象 | 变化 |
| --- | --- |
| 第 N 问、其回答、图表 | 删除 |
| 第 N+1 至末尾全部问答 | 级联删除 |
| 第 1 至 N-1 轮 | 保留生效 |
| 数据集 | **保留**（第一条问答之前上传的数据集不随删除丢失） |
| 删除第一条后 | 历史为空，用户可从数据集重新提问 |

### 4.3 上下文一致性不变量（已确认）

- **单一事实源**：Agent 当前上下文 = 界面中仍然有效并展示的问答，二者严格一致。
- 失效或已删除的回答、图表不进入上下文。
- 修改/删除为对生效历史的原子操作：操作确认前历史不变；操作完成前 Agent 不基于中间状态回答（操作期间的输入锁定/排队为建议，见 U-A）。

## 5. 状态设计

### 5.1 问答轮状态

| 状态 | 含义 | 进入 | 退出 |
| --- | --- | --- | --- |
| `active` | 生效中，参与上下文 | 回答生成完成 | 上游修改→`stale`；删除→移除 |
| `generating` | 回答生成中 | 提问/重新执行/重试提交 | 完成→`active`；失败→`failed` |
| `stale` | 因上游修改失效；问题文本仍展示，回答与图表失效 | 上游问题被修改 | 用户重新执行→`generating`，成功后新回答 `active` |
| `failed` | 重新回答失败；新问题文本保留，旧回答仍失效 | 生成出错 | 重试→`generating` |
| `deleted` | 已从历史移除（级联） | 删除确认 | 不可恢复（本轮无撤销） |

### 5.2 关键状态迁移

| 当前状态 | 事件 | 下一状态 | 可见结果 |
| --- | --- | --- | --- |
| `active`（第 N 问） | 确认修改 | 第 N 问文本更新；第 N 轮回答→`stale`；其后所有轮→`stale`；新回答 `generating` | 影响提示→编辑关闭→重新生成中 |
| `active`（第 N 问） | 确认删除 | 第 N 问及之后全部→`deleted` | 界面移除，历史更新 |
| `stale`（问题条目） | 用户点击重新执行 | `generating` | 基于当前生效上下文生成新回答 |
| `generating`（重新回答） | 生成失败 | `failed` | 错误提示 + 重试入口；**新问题文本保留，旧回答仍失效，不回滚** |
| `failed` | 重试成功 | `active` | 回答与修改后问题一致 |
| 第一条被删除 | 确认删除 | 历史为空 | 空态提示可从数据集重新提问 |

## 6. 角色、权限与数据

- **已确认**：单用户会话，会话所有者拥有全部操作权限；无多人协作。
- **数据副作用**：修改/删除改变生效历史；数据集在删除第一条后仍保留。
- **建议（待确认）**：保留操作审计记录（原问题文本、操作时间）用于追溯；保留期限属未知 U-B。
- 无新增收费或数据外发副作用。

## 7. 正常路径、异常路径与验收

### 7.1 正正常路径与验收断言

| 路径 | 操作 | 可验收断言 |
| --- | --- | --- |
| 修改中间问题 | 问 Q1、Q2、Q3→修改 Q2 | ① Q1 轮原样生效；② Q2 文本已更新，旧回答与图表失效；③ Q3 问题文本仍展示、旧回答与图表失效；④ 新回答内容与修改后问题一致；⑤ 后续新提问上下文不含任何失效内容 |
| 手动重新执行 | 修改 Q2 后点击重新执行 Q3 | 新回答基于 Q1+新 Q2+Q3 生成且生效 |
| 删除中间问题 | 问 Q1、Q2、Q3→删除 Q2 | ① Q2、Q3 及回答、图表全部移除；② Q1 保留生效；③ 后续提问不引用已删内容 |
| 删除第一条 | 删除 Q1 | 历史为空；数据集仍在；可重新提问且回答正常 |
| 图表联动 | 修改上游问题 | 下游失效图表不进入上下文；重新执行后生成的新图与新数据一致 |

### 7.2 异常路径

| 异常 | 行为 | 验收断言 |
| --- | --- | --- |
| 修改后重新回答失败 | 新问题文本保留；旧回答与图表仍失效；该轮 `failed`；提供重试 | 重试入口可用；重试成功后回答与修改后问题一致；无回滚 |
| 编辑后问题为空/超长 | 前端校验禁止提交（建议） | 无空问题进入历史 |
| 操作确认前网络/服务中断 | 历史不变，提示失败 | 无中间态（无“半删除”） |
| 生成进行中用户发起修改/删除 | **未知 U-A**：建议取消进行中生成再执行操作 | 无基于旧上下文的回答混入新历史 |
| 删除后立即新提问 | 基于删除后历史回答 | 不引用已删内容 |

### 7.3 上下文一致性验收口径（依据已确认规则 ⑤ 设计）

删除 Q2 后追问“刚才第二个问题的结论是什么”，Agent 应基于删除后的生效历史作答（即当前的第二问），不引用已删内容。此测试设计依据确认规则推导，执行前建议需求方认可该口径（U-C）。
