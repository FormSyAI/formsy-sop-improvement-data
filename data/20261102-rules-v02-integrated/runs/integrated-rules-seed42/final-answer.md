# 设计稿送审与客户确认工具设计

## 一、业务理解
本工具旨在为工作室提供设计稿送审与客户确认的数字化流程，支持以下核心业务场景：
1. 设计师上传设计稿并创建多个版本
2. 项目负责人审核并发布设计稿
3. 客户查看已发布版本并提出修改意见
4. 客户确认设计稿版本
5. 版本更新后的历史追溯与状态管理
6. 意见与确认的关联管理

## 二、规则与未知
### 已知规则
1. 账号系统：需要实现登录验证、角色绑定（设计师/负责人/客户）和访问控制
2. 项目管理：每个项目需指定客户确认人，其他客户可提意见
3. 版本管理：每个设计稿有多个版本，新版本发布后旧版本保持可读
4. 审核流程：审核通过后自动发布，旧版本不可修改
5. 意见管理：意见必须关联具体设计稿及版本，新版本发布后旧意见保留
6. 确认管理：客户确认后需要修改需提交申请，负责人接受后开启新流程
7. 历史追溯：所有操作（上传、审核、发布、确认）均需记录
8. 文件管理：支持图片和PDF上传，允许下载，撤销访问不能收回已下载副本
9. 沟通机制：负责人需手动通知客户，不自动发送消息

### 未知事项
1. 文件存储方案（云端存储/本地存储）
2. 文件格式限制（最大尺寸/支持格式）
3. 意见提交的格式要求（文字长度限制/附件支持）
4. 项目成员权限管理细节（能否查看其他项目）
5. 通知机制的具体实现方式（邮件/短信/站内信）
6. 客户确认后的流程变更管理
7. 系统的容灾和数据备份方案
8. 用户操作日志的详细程度和存储周期

## 三、关键状态及权限
### 状态管理
1. 设计稿状态：未上传/已上传/待审核/已发布/已确认
2. 版本状态：草稿/已发布/已确认
3. 意见状态：待处理/已处理/已确认
4. 项目状态：活跃/已关闭

### 权限管理
| 角色 | 权限 |
|------|------|
| 设计师 | 上传设计稿，创建版本，查看自己参与的项目 |
| 项目负责人 | 审核设计稿，发布版本，处理客户意见，管理项目成员 |
| 客户 | 查看已发布版本，提交修改意见，确认版本，查看历史记录 |
| 管理员 | 管理用户权限，配置系统参数，查看系统日志 |

## 四、数据与接口
### 数据模型
1. 用户表：用户ID、用户名、密码、角色、所属项目
2. 项目表：项目ID、项目名称、负责人ID、客户确认人ID、状态
3. 设计稿表：设计稿ID、项目ID、设计师ID、名称、描述、状态
4. 版本表：版本ID、设计稿ID、版本号、文件URL、状态、上传时间
5. 意见表：意见ID、版本ID、客户ID、内容、页码、状态、提交时间
6. 确认记录表：确认ID、版本ID、客户ID、确认时间、备注
7. 操作日志表：日志ID、用户ID、操作类型、操作对象、操作时间、详情

### 接口设计
1. 用户登录接口：POST /api/auth/login
2. 项目管理接口：GET/POST/PUT/DELETE /api/projects/{projectId}
3. 设计稿管理接口：GET/POST/PUT/DELETE /api/designs/{designId}
4. 版本管理接口：GET/POST/PUT/DELETE /api/versions/{versionId}
5. 意见管理接口：GET/POST/PUT/DELETE /api/comments/{commentId}
6. 确认管理接口：GET/POST/PUT/DELETE /api/confirmations/{confirmationId}
7. 操作日志接口：GET /api/logs

## 六、可验证的验收场景
1. **设计稿上传验证**
   - 输入：设计师上传设计稿和多个版本
   - 输出：系统应正确存储设计稿和版本信息，并在项目中显示

2. **审核流程验证**
   - 输入：项目负责人审核设计稿
   - 输出：审核通过后设计稿应自动发布，旧版本应保持可读

3. **意见提交验证**
   - 输入：客户提交修改意见
   - 输出：意见应正确关联设计稿和版本，并在系统中显示

4. **确认流程验证**
   - 输入：客户确认设计稿版本
   - 输出：系统应记录确认信息，并允许查看历史确认记录

5. **版本更新验证**
   - 输入：设计师上传新版本
   - 输出：旧版本应保持可读，新版本应为最新状态

6. **历史追溯验证**
   - 输入：查看项目历史记录
   - 输出：系统应完整显示所有操作记录（上传、审核、发布、确认）

7. **文件管理验证**
   - 输入：下载设计稿文件
   - 输出：文件应正确下载，撤销访问后已下载副本应仍可访问

8. **权限验证**
   - 输入：不同角色用户访问系统
   - 输出：用户应只能访问自己有权限的项目和设计稿
